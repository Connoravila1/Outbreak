Outbreak: Humanity’s Last Stand
Game Design Document (GDD)
Version: 1.0Date: 2025-10-18Author: 365 Digital Tech
1. Game OverviewTitle: Outbreak: Humanity's Last StandGenre: Real-world GPS-based Faction PvP (Zombies vs. Humans)Platform: Android & iOSEngine: Unity (with Firebase + GPS Plugins)Core Concept:Players select a faction (Human or Zombie) and use real-world GPS to navigate, collect loot, and engage in PvP combat with opposing players. Gameplay is built around live location proximity, territory control, and clan-based conflict.2. Gameplay Mechanics2.1 Faction Choice- At registration, players choose: Human or Zombie- Each faction has unique buffs and visual styles2.2 Movement & GPS Tracking- Player location is updated every 5 seconds- Real-world map is rendered using Mapbox SDK- Players can walk around their environment to encounter loot, allies, or enemies2.3 Combat System- Automatic real-time combat triggered when players from opposing factions are within 50 ft- Combat uses player stats:  - Attack  - Defense  - Speed  - Faction buffs- Combat ends when one player’s HP reaches 0; winner earns XP and loot2.4 Loot System- Random loot drops every 5–10 minutes in populated areas- Loot includes:  - Weapons  - Buff items (speed, regen, attack)  - XP tokens  - Territory flags (used for claiming zones)  - Cosmetics- Items have rarity tiers: Common, Uncommon, Rare, Legendary2.5 Progression System- XP earned through combat, distance traveled, item pickups- Level increases provide stat boosts and unlock abilities- Inventory capacity expands with level- Cosmetic upgrades unlockable through milestones or purchase2.6 Clans & Territories- Players can create/join clans (min level 10, max 50 members)- Territories can be claimed using territory flags at special drop zones- Clan perks apply when multiple adjacent zones are held- Weekly leaderboard reset and zone purges to maintain balance2.7 Safe Zones- Churches, hospitals, and schools are designated as Safe Zones- No combat or loot drops inside zones- Map indicators alert players when they enter or leave a zone3. User Interface (UI)- Login Screen: Email, Google, Apple sign-in- Faction Select & Avatar Customization: Gender, race, faction skins- Main HUD:  - Real-time map  - Nearby players  - Safe zone indicators  - Loot pin markers- Combat Overlay: Display stats, HP bars, combat results- Clan Tab: Create/join clans, manage members, view territory- Inventory: Item descriptions, usage, rarity tags- Store: XP boosts, cosmetics, inventory upgrades4. Monetization Strategy- Cosmetic purchases (skins, avatars, map themes)- XP boosts and inventory expansions- Season Pass with exclusive rewards- Optional ad-watching for minor loot5. Social & Engagement Features- Clan chat and push notifications- Weekly PvP leaderboard- Limited-time global events (e.g., Legendary Infected Raids)- AR mode (future release)6. Technical Stack Summary- Unity (LTS) + Mapbox + Unity LocationService- Firebase (Firestore, Auth, Cloud Functions, Messaging)- Android Studio / Xcode for builds- Firebase Hosting or Azure for backend logic
